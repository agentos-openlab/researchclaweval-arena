# 常见问题

[English](FAQ.md)。完整要求见[运行与评分规则](rules.md)。

## 任务与运行

**当前提供哪些任务和框架？**

当前有 BabyLM-10M、MountainCar-Continuous、ARC-WBE-2026、PsyDefDetect 和 TDC-ADMET-Tox 五项任务。七个内置框架适配器及各任务路由状态可通过 `python3 scripts/arena.py list` 查看。

**能否一条命令运行全部任务和框架？**

可以。七个内置适配器均声明了五项任务的启动命令。使用以下命令按顺序运行完整的 35 组组合：

```bash
python3 scripts/arena.py run --topic all --framework all
```

可先使用 `--dry-run` 检查所选路由。所有路由在公开端到端验证前均标记为 `experimental`。自定义适配器中未支持的路由会记入摘要，并使批次以非零状态退出。

**能否接入自己的框架？**

可以。在本地目录中添加 `adapter.json`，通过 `--adapter` 指定。适配器须启动框架原生流程、输出原生标记，并满足任务契约。详见[适配器指南](participant_quickstart.zh-CN.md#添加适配器)。

**`experimental` 和 `unsupported` 分别表示什么？**

`experimental` 表示已有启动配置，但尚未完成公开端到端验证；`unsupported` 表示该任务没有声明启动命令。两种状态都不代表已取得核验成绩。

## 模型 API 与数据

**应配置哪种模型 API？**

仓库不指定模型 API 服务商。请根据所用框架选择兼容的服务，并在本地 `.env` 中填写服务地址、API Key 和模型名；不要提交密钥。详见[快速开始](participant_quickstart.zh-CN.md#配置模型-api)。

**如何准备数据？**

运行 `bash scripts/setup_datasets.sh --dataset <topic-id>`。脚本只下载所选任务，校验已公布的文件哈希，并将数据保存在本机 `data/` 目录。原始数据集不随仓库发布。

**框架能看到评测标签吗？**

不能。运行器按任务契约隔离数据：挂载前会移除 PsyDefDetect 评测记录的标签；TDC 测试标签仅供主机评分器读取；ARC 评分集不挂载到框架容器。具体边界见各任务契约。

**BabyLM 的分数经过独立复核吗？**

当前诊断评分器读取框架报告的验证集困惑度，将状态记为 `framework_self_reported`。在独立复算前，该分数不参与排名。

## 成绩与排名

**榜单如何排序？**

经核验的成绩按相同任务、模型和评测协议分组排序。不同任务或协议的原始分不合并为总分；同分并列。

**公开的历史榜单是本次比赛的正式排名吗？**

不是。历史榜单根据已归档的论文数据快照整理，并经过证据复核。比赛自测任务为 ARC-WBE-2026、PsyDefDetect 和 TDC-ADMET-Tox；自测成绩不决定比赛最终排名。正式评测由主办方在其他任务上运行。五项历史榜单见[中文版](../results/leaderboard.zh-CN.md)或[英文版](../results/leaderboard.md)。

**名次为空表示什么？**

该记录尚未核验、历史数据中缺失，或属于框架自报分。榜单可以保留其状态，但不参与排序。核验标准见[结果说明](../results/README.md)。

**本地运行会自动进入榜单吗？**

不会。新结果须经证据复核后才能发布。仅有本地分数或模型生成的报告不足以入榜。

**ARC-WBE 如何评分？**

批量运行器会在无网络的 Docker 容器内运行估计器，并使用框架可见的验证切分。单独的评分切分不会挂载给框架。

## 故障处理

**批次以非零状态退出时应检查什么？**

打开命令输出的批次目录，查看 `summary.json` 和相应路由的 `logs/e2e.log`。原因可能是路由不支持、API 配置缺失、下载或镜像构建失败、框架未完成运行，或评分器报错。实际状态会保留在摘要中。

**如何报告问题？**

提交 issue 时注明任务、适配器 ID、运行命令、摘要状态和最小复现步骤。分享日志前删除 API Key、私有地址和原始数据行。
